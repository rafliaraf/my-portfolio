## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/rafliaraf/my-portfolio.git

# Navigate to project folder
cd my-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
